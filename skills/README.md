# Build skills around your own work

A skill is a reusable procedure for one task. It reads current facts from the private wiki instead of storing business knowledge in its instructions. These examples are newly authored generic procedures, not Weeve's internal playbooks.

| Example | Use it for |
|---|---|
| [Answer with citations](answer-with-citations/SKILL.md) | A focused question with evidence, uncertainty and coverage |
| [Weekly review](weekly-review/SKILL.md) | Research, selected domain reports and one human decision agenda |
| [Draft in my voice](draft-in-my-voice/SKILL.md) | An unsent draft using an approved private voice guide |

For any file-capable agent, explicitly say “Read AGENTS.md and skills/answer-with-citations/SKILL.md, then answer this question.” Host-specific automatic discovery differs; follow your host's skill documentation if installing a private copy. The examples do not require installation or subagents.

Start from [the blank template](../templates/task-skill.md). Include a specific trigger, required inputs and permissions, narrow steps, output format, acceptance checks, one synthetic example and an evidence-gap case. Declare tool side effects and decision boundaries. Keep voice samples, customers, credentials and company methods in the private workspace. Review a skill's source/license/tools before installing third-party code.
