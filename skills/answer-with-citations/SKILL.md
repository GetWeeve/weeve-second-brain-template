# Answer with citations

Read AGENTS.md. Confirm the active workspace and processor policy before reading company material. Use catalog and a focused query; do not bypass denied results by opening raw files directly.

1. Identify the question, relevant time window and what would constitute an answer.
2. Run a focused query within a suitable byte budget. Try a source heading if lexical wording misses. Load only the permitted passages needed.
3. Answer directly. Cite exact source path, revision and section for factual claims. Distinguish observation, inference and uncertainty. Check comparable definitions before calculating a metric.
4. State missing coverage or conflicting evidence. A missing result does not establish that something did not happen.
5. If the answer suggests a durable correction, prepare a separate cited proposal and wait for the human decision.

Output: normally a short answer, supporting citations and one coverage note. This procedure does not write to source systems, send messages or approve its own proposals.

Synthetic example: fictional notes record 8 completed sessions out of 10 booked. Report 80% with that definition and citation; do not infer that a reminder caused the result.

Missing-data case: if cancellations are not defined, state the ambiguity and request the definition before comparing completion rates across periods.
